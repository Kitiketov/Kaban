# Realtime

Это самостоятельный .NET host (`Realtime.csproj`) с health endpoints.

**Здесь пока нет** SignalR Hub, JWT-auth, RabbitMQ consumers или отправки клиентских уведомлений. Это намеренно: взаимодействие сервисов команда реализует самостоятельно.

При реализации добавьте защищённый SignalR hub, проверку *access* JWT и доставку уведомлений **после** согласования формата межсервисных событий. Не копируйте пользовательские DTO или EF-сущности из `Api` в Realtime.
