# Worker

Это самостоятельный .NET host (`Worker.csproj`), пока без фоновых обработчиков.

Сейчас реализованы только `/health/live` и `/health/ready` (заглушка readiness, без проверок подключений).

**Сюда пока не добавлены:** MassTransit, RabbitMQ, consumers, retry, DLQ, idempotency и фоновые задания.
Команда, ответственная за взаимодействие, выберет контракты и устройство сообщений после изучения RabbitMQ.

Когда появится конкретная задача, размещайте фичи в `Features/<Name>/` и выделяйте необходимые слои, а не создавайте пустые четыре папки для каждой задачи заранее.
